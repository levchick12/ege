Задание 6. Исполнитель Черепаха

Варианты вопросов заданий:

Обозначения фигур:
Фигура 1: s1 на s2
Фигура 2: s3 на s4
На оси абсцисс range(l1, r1)
На оси ординат range(l2, r2)

Кол-во точек в пересечении (с учётом точек на линиях)
(r1 - l1) * (r2 - l2)

Кол-во точек в объединении (с учётом точек на линиях)
(s1 + 1) * (s2 + 1) + (s3 + 1) * (s4 + 1) - (r1 - l1) * (r2 - l2)

Кол-во точек в пересечении (без учёта точек на линиях)
(r1 - l1 - 2) * (r2 - l2 - 2)

Кол-во точек в объединении (без учёта точек на линиях)
(s1 - 1) * (s2 - 1) + (s3 - 1) * (s4 - 1) - (r1 - l1 - 2) * (r2 - l2 - 2)

Периметр пересечения
2 * (r1 - l1 - 1 + r2 - l2 - 1)

Периметр объединения
(s1+s2)*2 + (s3+s4)*2 - 2 * (r1 - l1 - 1 + r2 - l2 - 1)

Площадь пересечения
(r1 - l1 - 1) * (r2 - l2 - 1)

Площадь объединения
(s1*s2)+(s3*s4) -(r1 - l1 - 1) * (r2 - l2 - 1) 


Подключение всех команд модуля Черепаха
from turtle import *

Движение черепахи на step пикселей вперед по направлению головы
forward(step) / fd(step)

Движение черепахи на step пикселей назад по направлению головы
backward(step) / bk(step)

Поворот черепахи на step градусов вправо по направлению головы
right(step) / rt(step)

Поворот черепахи на step градусов влево по направлению головы
left(step) / lt(step)

Поднять перо
penup() / up()

Опустить перо
pendown() / down()

Перемещает Черепаху в указанные координаты
teleport(x,y)
 
Рисует точку деаметром size и цветом color в текущей координате Черепахи
dot(size, color)

Изменяет размер полотна
screensize(10_000, 10_000)

отключает анимацию
tracer(0)

неоюходимо указывать вместе с tracer
update()

заиораживает окошко
done()
